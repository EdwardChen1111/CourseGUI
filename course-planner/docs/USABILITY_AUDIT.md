## 已確認的問題與修正

| 問題 | 原有影響 | 本次改善與證據 |

| 誤用校方時間欄位 | 最新 1151 快照有 1,177 門時段無法辨識 | 優先使用標準 `Node`，保留 `ThreeNode` 原文；修正中文精簡格式、分隔符號及小寫代碼 |
| 單學期同步覆蓋整份索引 | 更新最新資料後歷年選單可能消失 | 局部同步合併索引；測試涵蓋歷史保留、新錯誤紀錄及來源恢復 |
| 資料固定在既有版本 | 不會自動取得新的官方學期 | 最新學期取自官方索引；每次部署與每日排程重新同步，失敗即停止發布 |

| 課表操作不足 | 缺少替代方案、備份、直接移除與復原 | 多方案、重新命名、移除／復原、確認清空、JSON 備份合併匯入、CSV 及列印 |

| 不明時段誤導衝堂判斷 | 缺少時間可能被當成無衝堂 | 明確提示不能確認整份課表；可排課篩選排除不完整時段 |
| 缺少操作驗收 | 單元測試無法發現實際介面問題 | Playwright 瀏覽器操作測試納入 CI 與 Pages 發布前檢查 |

## 資料驗證結果

- 46 個可用學期，儲存庫快照共 94,863 筆開課班次。1151 重新同步為 4,303 門，0 門無法辨識時段；147 門未提供可排入課表的時間，保留未知狀態。
- 與原提交相同課號比較，共 16,194 門原本無法辨識的時段已修正（含最新與歷史學期）。歷史修復只更新時段與來源欄位，保留原快照擷取時間，另記 `scheduleVerifiedAt`；不把舊人數假裝成最新資料。
- 仍有 713 門歷史課程具有無法完整辨識的時間，主要是 1032 學期的舊式外校時間；不猜測數字範圍、零節次或特殊符號。46 學期中總計 5,402 門沒有可解析會議時段，與「解析失敗」不是同一統計。
- 官方 95–99 年度的 15 學期保留先前的來源不可用證據及日期。本次沒有重新宣稱已驗證這 15 學期。
- 官方 API 比對 6 組查詢：CS 系所、校區複選、教學類型複選、大學部、研究所及兩種學制同選。採逐課號集合比較，不僅比較數量；最新學期由索引選取。

## 可重現驗證

```bash
npm ci
npm run validate:data
npm run test
npm run lint
npm run build
npm run test:e2e
npm run verify:official
```

單元測試涵蓋時間、篩選、資料、課表備份、學分及索引合併。瀏覽器測試涵蓋首屏可用性、分頁、官方篩選、正確外校時段、非預設學期保存、方案切換、匯出／合併匯入、錯誤學期拒收、實際衝堂、時間不明、課號遺失、網路失敗重試、儲存失敗、毀損保護、手機寬度、已修課計算、規則年度限制與草稿建立保存。

`UI_VERIFY_URL` 可指定公開網站；測試資料只寫入獨立瀏覽器測試環境，不改動使用者的實際課表。截圖輸出至忽略提交的 `audit-artifacts/`，失敗診斷輸出至 `test-results/`。

Windows 在受限程序環境曾導致建置／測試暫存檔失敗；重新使用正常本機程序及清理本專案建置快取後完成驗證。這類環境失敗不當作產品測試通過。

## 目前仍有的限制

發布驗證：`12e1a86` 已通過 GitHub CI 與 Pages 發布；公開網站 8 組操作測試通過。線上 1151 資料於 `2026-10-29T10:56:56.275Z` 重新同步為 4,340 門；上述 4,303 門與總筆數描述的是已提交的本機快照，兩者擷取時間不同。

1. 尚未建置並人工覆核各系各年度的正式必修、雙主修與輔系規則庫。已提供草稿建立及匯入工具；不可宣稱已完成正式畢業審核。
2. 規則只逐群組比對使用者列出的課號及學分，尚無完整的跨群組分配、抵免、替代課程、通識特殊限制與跨系重複採計引擎。
3. 資料是快照；每日排程可能延遲或因校方 API 失敗而不更新。歷史學期不會在每日流程全部重抓，需依畫面擷取日期判讀。
4. 本機保存不等同帳號同步。清除瀏覽器資料、換裝置或換網域前應下載備份。沒有校務登入、正式選課送出或自動讀取成績。
5. 跨校時段依校方轉換資料，交通與校際實際鐘點差異仍需使用者確認。
