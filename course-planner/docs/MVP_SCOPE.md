# MVP 功能範圍與驗收基準

## 已交付且可驗證

- 校方公開課程 API 的受控同步、版本化靜態快照、schema 驗證與快照差異摘要。
- 完整學期快照與官方學期清單；依學期載入，明確揭露來源與擷取時間，不以部分關鍵字快照充當全校查詢。
- 依課名、課號、教師、最低學分、必選修與上課日搜尋，顯示學分、開課類型、時段、去重後教室、名額狀況與校方備註；加入／移出候選課表、學分加總、衝堂提示與每週格狀課表。
- 每學期的多份候選課表只存在使用者瀏覽器，可備份還原、匯出 CSV、列印與復原移除；快照找不到的已存課號仍保留並提示核對。
- 獨立修課紀錄、重修去重、主系／雙主修／輔系規則匯入與畫面草稿編輯器；不同年度或學制阻止套用。候選課表不計入已通過學分；網站不再套用展示規則。
- GitHub Actions 更新最新學期，執行資料驗證、單元測試、lint、靜態建置及瀏覽器操作測試，再部署至 GitHub Pages。

## 待人工資料審核後交付

- 指定入學年度、學制與系所後，依官方原始表格建立並覆核正式主系、雙主修與輔系 requirement set。
- 正式規則發布前，使用受控匯入指令預覽群組與 metadata 差異；只有明確的 `--write` 才能更新部署資料。
- 跨群組學分分配、跨系抵免、替代課號與各系特殊畢業條件尚未完整建模。現在僅逐群組依使用者列出的課號檢查，不可視為正式畢業審核。

## 不在 MVP 範圍

- 校務 SSO、正式選課送出、自動讀取成績；此專案不收集密碼。使用者可自行在本機記錄課程及通過狀態，不輸入成績分數。
- 課程評價、社群留言、交易或錢包功能；這些需要獨立的社群治理、授權與安全設計。

完整的資料匯入規範見 [REQUIREMENT_REVIEW.md](REQUIREMENT_REVIEW.md)，每次功能與驗證紀錄見 [PROGRESS.md](PROGRESS.md)。
