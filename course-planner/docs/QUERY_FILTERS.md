# 校方課程查詢功能對照

## 資料與部署方式

以 Next.js 靜態匯出並由 GitHub Actions 部署 GitHub Pages。校方 API 未提供 Pages 所需的跨來源讀取允許標頭，因此瀏覽器不直接連線校方 API，也不使用公開代理。

`npm run sync:catalog -- --write` 讀取官方學期、學院、系所與通識向度清單，取得各學期完整課程，並查詢官方篩選結果建立課程分類。大型清單依課程代碼分批查詢；任何批次失敗皆中止，不發布不完整索引。`--resume` 可接續已完成快照；重新更新請不要使用 resume。

課程快照位於 `public/courses/`，索引位於 `src/data/catalog-index.json`。前端依所選學期載入並驗證 JSON，不一次載入所有歷年資料。候選課表依學期分開保存在本機。

課程人數是資料擷取時的人數，不是即時名額；缺少時間的課程不自行推測時段。

`npm run sync:catalog -- --write --index-only` 可從已驗證的既有完整快照重建索引，不發出課程查詢。學期同步可以接續，尚未完成的學期不會出現在部署索引。

`--audit-unavailable` 會另行檢查不可用的兩位年度學期；`--require-complete` 要求官方每個學期都有完整快照或經確認的來源錯誤紀錄。95–99 年度的官方清單格式會被 API 回覆 HTTP 400；補為三位年度雖回覆 HTTP 200，資料卻為空。這些學期獨立列為來源不可用，不發布空課程快照，也不宣稱沒有開課。

本次對齊公開課程查詢的篩選條件，不包含校務登入、正式選課、獨立停開課程查詢或歷年課名／大綱彙總專區。

## 額外驗證

`npx tsx scripts/verify-official-query.ts` 唯讀比對官方 API 與本機資料的系所、校區複選、教學類型複選及學制案例。

`node scripts/verify-query-ui.cjs` 以無視窗 Edge 實測靜態匯出；需要可用的 Playwright runtime，可透過 `PLAYWRIGHT_MODULE` 指定模組位置。`UI_VERIFY_URL` 可改為公開網址。測試包含年度索引與停用選項一致性、篩選、最早年度、暑期、分學期保存、載入失敗重試與手機版寬度。

## 功能對照

| 校方條件 | 實作 |
| --- | --- |
| 學年度、學期、暑期、歷年 | 依官方學期清單建立兩級選單 |
| 課程代碼、名稱、教師 | 各自查詢，可同時使用 |
| 學院、系所學程 | 官方學院／系所對照，學院全部系所或指定系所 |
| 校區 | 校本部、華夏、新竹，可複選 |
| 台科大／外校 | 所有學校、僅台科大、台大與師大、僅台大、僅師大 |
| 課程類別 | 通識、體育、國文、外語、師培 |
| 通識向度 | 官方向度清單 |
| 教學選項 | 英語、業師、PBL、遠距、創新教學、EMI、密集課程 |
| 學制限制 | 研究所、大學部 |
| 時間 | 週一至週日，1–10、A–D，共 98 節次；全選、清除、整日選取 |
| 僅列出勾選節次 | 全部已知上課節次須在指定範圍；未知時段不視為符合 |
| 額外規劃條件 | 最低學分、必選修、星期、跨欄位文字搜尋 |
| 顯示數量 | 50、100 或全部符合課程 |

不同條件群組取交集；校區複選為任一校區符合，教學類型複選為所有所選類型皆符合（已與官方 API 實際結果對照）。一般時間選取是至少一節符合；嚴格模式是整門課皆符合。

資料來源：[官方查詢頁](https://querycourse.ntust.edu.tw/QueryCourse/#/)、[官方課程 API](https://querycourse.ntust.edu.tw/querycourse/api/courses)。分類採官方查詢結果，不以教室名稱或課名猜測校區、通識或教學類型。
